# Child-Quine
纯整活 Python 嵌套套娃奎因项目

## 项目介绍
这是一个**抽象娱乐向的分布式奎因套娃实验**。

所有子副本**没有自主决定权**，
每一次繁衍新副本，都必须向主控 `main.py` 请求授权令牌。

主程序统一管控全局计数器，
令牌耗尽，整条套娃繁衍链路自动终止。

## 运行机制
1. `main.py` 全局唯一主控、令牌管理中心
2. 所有 child 副本启动后必先查询剩余次数
3. 次数大于 0：复制自身代码、生成新副本并运行
4. 次数等于 0：立刻终止套娃，停止繁衍

## 文件说明
- `main.py`：主控核心程序
- `child_*.py`：程序自动生成的嵌套副本

## 运行方法
```bash
python main.py
```
⚠️ **警告**
请勿设置**过大**的`max_pass`数值
会批量生成大量脚本文件，造成磁盘爆满。 
**补充声明**
本项目仅为编程趣味整活，
不属于数学严格定义的标准奎因程序。
